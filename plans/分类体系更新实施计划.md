## 技术细节

### 分类代码解析规则
1. **一级分类**：单个字母（A-Z）
2. **二级分类**：字母+数字（如B0, B5）
3. **三级分类**：字母+数字+分隔符+数字（如B0-0, B01）
4. **四级分类**：更复杂的组合（如B109.2）

### 父子关系推断算法
```python
def infer_parent_code(code):
    if '-' in code:
        # 如B0-0的父类是B0
        return code.split('-')[0]
    elif len(code) > 1 and code[-1].isdigit():
        # 如B01的父类是B0
        return code[:-1]
    elif len(code) > 1:
        # 如B5的父类是B
        return code[0]
    else:
        # 一级分类没有父类
        return None
```

### 权重分配策略
1. **常用学科**：计算机科学、经济、医学等分配较高权重
2. **基础学科**：数学、物理、化学等分配中等权重
3. **专业学科**：细分专业领域分配较低权重
4. **总权重**：保持总和为1000左右，便于概率计算
